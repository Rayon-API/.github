# RayonAPI

Generate Shape telemetry from a source URL, profile and exact request. Rayon manages material for supported public header flows. Explicit uploads and private references remain optional.

**We recommend an SDK.** Follow the [Quickstart](https://docs.rayonapi.com/quickstart): install → check usage for free → send request context → generate → apply the result with your existing integration.

| SDK | Get started |
| --- | --- |
| [Python](https://github.com/Rayon-API/rayon-sdk-py) | `python -m pip install 'rayon-sdk-py>=2.1.0,<3'` |
| [JavaScript / TypeScript](https://github.com/Rayon-API/rayon-sdk-js) | `npm install rayon-sdk-js@^2.1.0` |
| [Go](https://github.com/Rayon-API/rayon-sdk-go) | `go get github.com/Rayon-API/rayon-sdk-go/v2@v2.1.0` |
| [Playwright](https://github.com/Rayon-API/rayon-sdk-playwright) | `npm install rayon-sdk-playwright@^1.1.0 playwright-core` · optional existing-page integration |
